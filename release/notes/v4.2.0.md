Version 4.2.0 adds a **macOS app**.

## Added

- macOS app for Apple silicon and Intel Macs (macOS 13 Ventura or newer). All
  login methods work: the embedded browser (WebKit), Firefox or Brave, and
  pasting the login cookie. Logins are kept in the macOS Keychain.

See the [complete changelog](https://github.com/touhid314/Coursera-Downloader/blob/v4.2.0/changelog.md#v420)
for details.

## Downloads

### Windows

- **Installer** (`CourseraDownloaderInstallerV4.2.0.exe`): recommended for
  most Windows users.
- **Portable ZIP**: extract the full folder, then run `CourseraDownloader.exe`.

### macOS

- **Apple silicon** (M1 and newer): `CourseraDownloader-v4.2.0-macos-arm64.dmg`
- **Intel**: `CourseraDownloader-v4.2.0-macos-x86_64.dmg`

Open the disk image and drag **Coursera Downloader** to **Applications**. The
app is not notarized by Apple, so macOS blocks it the first time. To open it:

- macOS 15 and newer: try to open the app, then go to **System Settings →
  Privacy & Security** and click **Open Anyway**.
- macOS 13 and 14: Control-click the app in Applications and choose **Open**.

Or run `xattr -dr com.apple.quarantine "/Applications/Coursera Downloader.app"`
in Terminal.

**SHA256SUMS.txt** lists checksums for verifying every download.
