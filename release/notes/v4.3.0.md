Version 4.3.0 adds a **Linux app**.

## Added

- Linux app for 64-bit (x86-64) Linux, such as Ubuntu 22.04 or newer. All
  login methods work: the embedded browser, Firefox or Brave, and pasting the
  login cookie. Updates install from inside the app.

See the [complete changelog](https://github.com/touhid314/Coursera-Downloader/blob/v4.3.0/changelog.md#v430)
for details.

## Downloads

### Windows

- **Installer** (`CourseraDownloaderInstallerV4.3.0.exe`): recommended for
  most Windows users.
- **Portable ZIP**: extract the full folder, then run `CourseraDownloader.exe`.

### macOS

Requires macOS 13 Ventura or newer. Open **Terminal** and run:

```sh
curl -fsSL https://raw.githubusercontent.com/touhid314/Coursera-Downloader/main/install-macos.sh | bash
```

It installs the right version for your Mac (Apple silicon or Intel) in
Applications, without macOS's security warning.

Or download the disk image yourself (`…-macos-arm64.dmg` for Apple silicon,
`…-macos-x86_64.dmg` for Intel), drag **Coursera Downloader** to
**Applications**, then run
`xattr -dr com.apple.quarantine "/Applications/Coursera Downloader.app"` in
Terminal, because the app is not notarized by Apple.

### Linux

Open a terminal and run:

```sh
curl -fsSL https://raw.githubusercontent.com/touhid314/Coursera-Downloader/main/install-linux.sh | bash
```

It installs the app for your user, without administrator rights, and adds it
to the applications menu. Or download `CourseraDownloader-v4.3.0-linux-x86_64.tar.gz`,
extract it, and run `CourseraDownloader/CourseraDownloader`.

**SHA256SUMS.txt** lists checksums for verifying every download.
