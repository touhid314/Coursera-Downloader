Version 4.2.1 fixes updating the macOS app.

## Fixed

- **macOS:** the **Update** button in the "Update available" message opened
  the Windows installer. It now opens Terminal and installs the new Mac
  version, then reopens the app.

Mac users of 4.2.0: install 4.2.1 with the command below. Later updates then
work from inside the app.

See the [complete changelog](https://github.com/touhid314/Coursera-Downloader/blob/v4.2.1/changelog.md#v421)
for details.

## Downloads

### Windows

- **Installer** (`CourseraDownloaderInstallerV4.2.1.exe`): recommended for
  most Windows users.
- **Portable ZIP**: extract the full folder, then run `CourseraDownloader.exe`.

### macOS

Requires macOS 13 Ventura or newer. Open **Terminal** and run:

```sh
curl -fsSL https://raw.githubusercontent.com/touhid314/Coursera-Downloader/main/install-macos.sh | bash
```

It installs the right version for your Mac (Apple silicon or Intel) in
Applications, without macOS's security warning.

Or download the disk image yourself:

- **Apple silicon** (M1 and newer): `CourseraDownloader-v4.2.1-macos-arm64.dmg`
- **Intel**: `CourseraDownloader-v4.2.1-macos-x86_64.dmg`

Drag **Coursera Downloader** to **Applications**. The app is not notarized by
Apple, so macOS blocks a downloaded copy until you run
`xattr -dr com.apple.quarantine "/Applications/Coursera Downloader.app"` in
Terminal.

**SHA256SUMS.txt** lists checksums for verifying every download.
