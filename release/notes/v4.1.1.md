Version 4.1.1 is a security update. Please update.

## Security

- The app sent your Coursera login cookie to every website it contacted,
  including third-party sites linked from course materials. Anyone running
  such a site could have used it to access your Coursera account. The cookie
  is now sent only to coursera.org, and only over HTTPS. Thanks to
  @Muhammad-Danyal353 for pull request #20, which pointed this out.

  If you are worried that your login was exposed, log out of Coursera in your
  browser and log in again: this ends the old session.

## Fixed

- Running from source failed on a clean install (missing `packaging` module).
- No longer uses `distutils`, which newer Python versions removed.
- Secure connections now allow TLS 1.3.

See the [complete changelog](https://github.com/touhid314/Coursera-Downloader/blob/v4.1.1/changelog.md#v411)
for details.

## Downloads

- **Installer:** recommended for most Windows users.
- **Portable ZIP:** extract the full folder, then run `CourseraDownloader.exe`.
- **SHA256SUMS.txt:** checksums for verifying both downloads.
