Version 4.0.0 is a substantial modernization of Coursera Full Course
Downloader.

## Highlights

- Redesigned PySide6 interface with high-DPI and system-theme support.
- Persistent embedded Coursera login using WebView2 and the Windows credential
  vault, with Firefox and Brave login as alternatives.
- Enrolled-course discovery and direct support for course, specialization, and
  professional-certificate links.
- Detailed in-app and Windows taskbar progress, completion notifications, stop,
  and resumable downloads.
- Downloads for videos, subtitles, readings, assignments, quizzes, notebooks,
  and other available course resources.
- Reliable Windows paths containing spaces and improved validation and error
  handling.
- Reorganized source, automated tests, and a repeatable Windows release process.

See the [complete changelog](https://github.com/touhid314/Coursera-Downloader/blob/v4.0.0/changelog.md#v400)
for details.

## Downloads

- **Installer:** recommended for most Windows users.
- **Portable ZIP:** extract the full folder, then run `CourseraDownloader.exe`.
- **SHA256SUMS.txt:** checksums for verifying both downloads.
